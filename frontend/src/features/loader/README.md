# Écran de chargement (`features/loader`)

| Fichier | Rôle |
|---|---|
| `PageLoader.jsx` + `.css` | l'écran plein écran, qui s'efface en fondu |
| `DotMolecule.jsx` + `.css` | les petits points qui forment la molécule puis respirent |
| `moleculeDots.js` | calcule la place, le départ et le retard de chaque point |
| `useReadyWithTimeout.js` | l'état « prêt », avec une durée minimale et une durée maximale |
